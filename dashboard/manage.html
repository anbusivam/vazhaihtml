📁 Upload Direct Bank Payments via CSV

Batch-upload manual payment records (Account Transfer / Cash) using a CSV file. These will appear in the payment history above.

📋 CSV Format Instructions
Your CSV should have these columns (header row required):
DATE, RECEIPT NO, PAYMENT ID, NAME, EMAIL, AMOUNT, METHOD, PAN, notes
Column details:
• DATE — Payment date (YYYY-MM-DD format)
• RECEIPT NO — Receipt number for your records (stored as receiptNo)
• PAYMENT ID — Bank transaction ID (used as the payment ID). Must be unique.
• NAME — Donor's full name (required)
• EMAIL — Donor's email address (required)
• AMOUNT — Donation amount in ₹ (required, numbers only)
• METHOD — ACCOUNTTRANSFER or CASH (required)
• PAN — Donor's PAN card number (optional)
• notes — Any notes/comments (optional)

Example row:
2026-06-24,2006/06/24/01,Q2345234234234234,John Doe,john@example.com,1000,ACCOUNTTRANSFER,ABCDE1234F,Monthly donation

📝 Thank You Letter Template

Edit the HTML template used when sending thank-you emails to donors. The template supports these placeholders that will be replaced dynamically:

[donor-name] — Donor's name (from payment; can also use [user-name] or [user-tamilname] instead)
[donation-amount] — Donation amount (e.g. ₹1,000.00)
[donation-date] — Date of donation
[donor-mail-id] — Donor's email address
[user-name] — User's saved name (from profile; error if missing)
[user-tamilname] — User's saved Tamil name (from profile; error if missing)
